# Santo Rosario

App para rezar el Santo Rosario de la Virgen María, cuenta por cuenta.

- Elige sola los misterios del día (Gozosos, Dolorosos, Gloriosos o Luminosos).
- Cita bíblica y meditación de cada misterio que cambian cada día.
- Frase del día, intención personal y progreso guardado en el dispositivo.
- Opcionales: Oración de Fátima, jaculatorias, Letanías y Oración a San Miguel Arcángel.

Para usarla, abre `index.html` en el navegador o publica el repositorio con GitHub Pages.
